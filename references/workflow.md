# 网页生成工作流

## 模式一：生成网页

1. 调用 Skill，识别页面需求。
2. 与用户确认页面风格。
3. 从 `web-prompts/` 选择并读取对应的风格模板。
4. 检查目标项目的框架、组件库、构建工具和已有页面。
5. 判断是新建网页还是复用已有架构。
6. 新建网页时同步建立程序代码和页面 Markdown。
7. 复用已有架构时优先复用并调整目标项目已有 Markdown。
8. 只有现有代码不支持需求时，才扩展程序代码，并同步更新 Markdown 规范。
9. 使用目标项目的渲染方式生成网页。
10. 执行内容、视觉、布局、主题和代码一致性检查。

## 模式二：迭代网页风格

1. 用户明确要求沉淀或更新网页风格。
2. 检查目标项目的代码、页面 Markdown、截图和设计决策。
3. 区分可复用设计原则与页面专属内容。
4. 判断是更新已有 web-prompt，还是创建新的 web-prompt。
5. 先向用户展示修改建议，获得确认后再写入。
6. 更新或创建 `references/web-prompts/<style-name>.md`。
7. 执行风格模板自检，并记录变更。

## 文件归属

- 风格模板属于 Skill 资源库。
- 页面 Markdown 属于目标项目。
- 程序代码属于目标项目。
