# 网页自检清单

## 需求和风格

- [ ] 已与用户确认页面风格
- [ ] 使用了正确的 web-prompt
- [ ] 没有把风格模板误当成固定页面结构

## 风格迭代模式

- [ ] 用户明确要求沉淀或更新风格
- [ ] 已区分通用设计原则和页面专属内容
- [ ] 已判断应更新已有模板还是创建新模板
- [ ] 已获得用户对模板修改的确认
- [ ] 新模板没有写入业务文案、固定字段或页面专属逻辑

## 目标项目

- [ ] 已识别当前项目的框架和组件库
- [ ] 新网页已同时建立代码和页面 Markdown
- [ ] 复用网页时优先复用了已有架构和 Markdown
- [ ] 页面 Markdown 和代码位于目标项目中

## 渲染质量

- [ ] Markdown 内容完整渲染
- [ ] 主题、字体、背景和边框具有足够对比度
- [ ] 页面高度、滚动和响应式布局正常
- [ ] 加载、空数据和错误状态完整
- [ ] 没有不必要的页面级硬编码
