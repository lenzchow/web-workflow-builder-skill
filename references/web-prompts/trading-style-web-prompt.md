# Trading Style Web Prompt

## 适用场景

适用于金融研究、市场观察、量化分析、投资决策支持和数据密集型工作台。

## 设计方向

- 使用专业、克制、信息密度适中的金融终端风格。
- 优先建立稳定的工作区、导航区和内容区层级。
- 让用户先看到关键状态，再逐步查看详细数据。
- 保持大量数据下的清晰分组、对齐和可扫描性。

## 视觉语言

- 支持浅色、深色和护眼色主题。
- 页面背景、内容背景和卡片背景必须形成层级差异。
- 文字颜色、边框和分隔线必须随主题切换。
- 行情上涨和下跌使用稳定、明确且具有足够对比度的绿色和红色。
- 重要数据使用更高字重或更强对比度，不依赖过多装饰。
- 避免大面积纯白块、无意义渐变和过度圆角。

## 布局原则

- 使用清晰的页面标题、上下文说明和主要操作区。
- 根据内容重要性安排指标、趋势图、明细表和状态提示。
- 支持固定导航与独立内容滚动，避免整个页面被单一区域带动。
- 页面高度根据视口和内容自适应，不使用阻塞内容的固定高度。
- 不规定页面必须包含哪些区块；区块应根据业务目标自由增删和组合。

## 数据展示原则

- 先筛选与当前任务最相关的信息，再决定展示形式。
- 金额、百分比、倍数、日期和状态使用对应格式。
- 趋势数据优先使用图表，离散字段优先使用表格或指标卡。
- 显示数据来源、更新时间、缺失状态或待核实状态。
- 不使用单一判断标准解释所有指标。

## 交互原则

- 搜索、筛选、主题切换和页面导航应保持统一位置和行为。
- 加载、空数据、错误和不可用状态需要明确反馈。
- 复杂信息采用渐进式展示，避免初始页面过度拥挤。
- 交互反馈优先使用当前项目已有组件和模式。

## 实现约束

该 Prompt 只描述设计思路，不指定 React、Vue、HTML、Ant Design 或其他固定技术。具体实现由目标项目的技术架构决定。
