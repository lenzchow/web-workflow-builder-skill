# 页面 Markdown 规范

页面 Markdown 生成在目标项目中，用于保存当前项目的页面内容、结构和可配置表现。

## 可表达内容

- 页面标题和说明
- 导航名称和页面区块
- 区块顺序和显示条件
- 指标卡、表格、图表、列表、图片和注解
- 主题、布局和组件参数
- 加载、空数据和错误提示

## 边界

Markdown 不负责实现 API、业务逻辑、数据处理或组件内部行为。目标项目的代码负责解析 Markdown，并将配置映射到当前项目可用的组件和渲染方式。

## 示例

```md
---
page: overview
layout: workspace
theme: adaptive
---

# 页面标题

## 数据概览

| 指标 | 展示方式 | 格式 |
| --- | --- | --- |
| 收入 | 指标卡 | 金额 |
| 趋势 | 图表 | 时间序列 |
```
